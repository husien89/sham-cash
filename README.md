# ShamCash - Digital Wallet

## نظرة عامة
ShamCash هو محفظة رقمية حديثة مصممة بتقنيات الويب القياسية، مع واجهة عربية بالكامل.

## المميزات
- 💳 **محفظة رقمية** مع رصيد فوري
- 📱 **رمز QR** للدفع والاستلام
- 📜 **سجل معاملات** كامل
- 🔔 **إشعارات** فورية
- 📄 **تصدير PDF** لكشف الحساب
- 🔐 **نظام مصادقة** مع أدوار (Admin/User)
- 🌙 **تصميم متجاوب** يعمل على الجوال والكمبيوتر

## متطلبات التشغيل
- متصفح ويب حديث (Chrome, Firefox, Edge)
- لا يحتاج سيرفر (يعمل بتقنية LocalStorage)

## طريقة التشغيل
1. انسخ جميع الملفات إلى مجلد واحد
2. افتح `static/login.html` في المتصفح
3. سجل الدخول باستخدام:
   - **اسم المستخدم:** `admin`
   - **كلمة المرور:** `admin123`
