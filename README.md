# ShamCash

نموذج محفظة ويب عربي مبني بـ Flask وSQLite، مع مصادقة جلسات وكلمات مرور مجزأة.

## التشغيل

```bash
python -m pip install -r requirements.txt
python main.py
```

افتح `http://127.0.0.1:5000` وأنشئ حساباً من شاشة التسجيل.

## إعداد الإنتاج

- عيّن متغير `SECRET_KEY` إلى قيمة عشوائية طويلة وثابتة.
- شغّل التطبيق خلف HTTPS وعيّن `COOKIE_SECURE=true`.
- عيّن `DATABASE_PATH` لمسار قاعدة بيانات قابل للكتابة إن لم تكن تريد المسار الافتراضي في مجلد المشروع.
- لا تنشر قاعدة بيانات SQLite ولا ملفات `.env`.

## حدود المشروع

هذه نسخة تجريبية فقط؛ التحويلات عمليات خصم محلية ولا تنقل أموالاً حقيقية ولا تتصل بمزود دفع.
